DataHz Console

统一图形入口：目录汇总专页、任务执行工作台与实时监控面板。目录汇总场景可直接进入 Aggregation，复杂调试仍建议使用 Workbench。

Directory Aggregation

面向日常汇总操作：浏览模板文件、源数据目录、输出目录与区划代码文件，校验后直接发起异步汇总并查看进度结果。

打开 Aggregation

Task Workbench

面向操作人员：模板解析、计划生成、同步执行、异步提交、作业详情与取消。

打开 Workbench

Monitor Dashboard

面向监控与运维：队列概览、安全态势、外部密钥提供方健康、审计导出。

打开 Monitor

打开 Swagger
